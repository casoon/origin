# Architecture Contract

These rules are binding for every crate and package in this repository.
They are enforced by review, by `cargo xtask validate`, and by CI.

1. **Core never depends on Tauri.** No crate under `crates/` may depend on `tauri` or any `tauri-plugin-*`.
2. **Core never knows product identities.** No crate under `crates/` may reference `contoso`, `fabrikam`, `northwind` or any other product name.
3. **External APIs are isolated behind connectors or SDK crates.** No HTTP client leaks into domain code.
4. **Reusable functionality is developed context-free.** An SDK crate knows its API, nothing else.
5. **OS access happens through platform contracts.** Domain code depends on traits, never on OS APIs.
6. **Tauri plugins implement host capabilities.** They do not carry business logic.
7. **Apps assemble functionality through a composition root.** No hidden global registry.
8. **Product differences use configuration or strategies**, not forks of platform code.
9. **Cross-cutting reactions use typed events.**
10. **No string-based internal event protocol.**
11. **External services remain Source of Truth** unless explicitly documented otherwise.
12. **Shared abstractions follow the Promotion Rule** (see ADR-0009).
13. **Platform changes must build and test all reference applications.**
14. **Security follows Least Privilege.** No blanket `fs:*` or `shell:*` capability.
15. **Frontend views do not call unrestricted Tauri APIs directly.** They go through `@origin/client`.

## Layers

```text
PRODUCT APP            examples/demo, later other independent products
  ↓ composition root
DRIVING ADAPTERS       Tauri host · MCP server · CLI · headless — all equal peers
APPLICATION MODULES    ApplicationModule implementations
  ↓
CONNECTORS             external service integrations
  ↓
ORIGIN PLATFORM        crates/origin-{events,secrets,settings,storage,http,auth,
                       accounts,connector,sync,jobs,mcp,ai,telemetry,app}
TOOLING                crates/origin-{manifest,xtask} — build time, not runtime
  ↓
PLATFORM CONTRACTS     crates/origin-platform, crates/origin-core (ports)
  ↓
TAURI HOST             host/origin-tauri, adapters/origin-*-tauri
```

Dependencies point **downwards only**. An adapter may depend on a contract crate;
a contract crate may never depend on an adapter.

## Dependency rules (machine-checked)

| Layer | May depend on | Must never depend on |
| --- | --- | --- |
| `crates/*` | other `crates/*`, third-party libs | `tauri*`, `adapters/*`, `host/*`, `examples/*` |
| `adapters/*` | `crates/*`, platform libs | other `adapters/*`, `examples/*` |
| `host/*` | `crates/*`, `adapters/*`, `tauri*` | `examples/*` |
| `examples/*` | everything | — |

Run `cargo xtask validate` to check them. It also verifies that every command the
frontend calls by name exists as a `#[tauri::command]` — the one place where a rename
would otherwise only fail in front of a user.

## File ownership

A file generated by `cargo xtask generate` is **Origin-owned**: it is overwritten on
every run and must never be hand-edited (ADR-0022). `cargo xtask generate --check` runs
in CI and fails on a hand-edit or a stale file.

To change an origin-owned file, change `app.toml`. To change what a security profile
*means*, change it in `origin-manifest` — where it changes for every Origin application
at once.

## Escape hatch

A product may deviate from a recommendation, but the deviation must be explicit —
either in the app manifest under `[origin.overrides]` or as an ADR in `adr/`.
Silent deviation is a bug.
